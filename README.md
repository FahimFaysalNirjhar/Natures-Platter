# 🌿 Nature's Platter

## 📖 Description

Nature's Platter is a responsive e-commerce landing page built using **Tailwind CSS** and **DaisyUI**.  
It showcases products, services, offers, and a contact form.

**Key Feature:**

- ✨ A **typewriter animation** implemented **purely in CSS** (no JavaScript).

## ⭐ Features

- 📱 Fully responsive design using **Tailwind CSS**.
- 🎨 Styled components using **DaisyUI**.
- ⌨️ CSS-only typewriter effect for animated text.
- 🛒 Product showcase with hover effects.
- 🎁 Offers section with promotional banners.
- ✉️ Contact form with inputs and textareas.
- 🔗 Footer with social media links.

## Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/natures-platter.git
   ```

---

## 💻 Tech Stack

- **Front-end:** HTML5, Tailwind CSS, DaisyUI
- **No back-end** included (front-end focused)
- **Optional JS:** Small interactive features like typewriter effect

✅ No JavaScript required for the typewriter effect.
